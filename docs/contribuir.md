# Contribuir

1. Abra issue descrevendo o tipo de documento e o comportamento esperado.
2. Inclua recorte mínimo reproduzível em `examples/` (texto público).
3. Rode `uv sync` e `uv run python scripts/validate_manual.py` após `fetch_samples`.
4. Preserve a semântica da LC 95/1998; não “adivinhe” estrutura onde o texto é narrativo.
5. Não publique material privado do produto Como Votam.

Código sob Apache-2.0.
